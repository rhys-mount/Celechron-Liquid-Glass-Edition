# 二级页面 UI 审查（2026-11-17）

本报告为优化建议，不改变已确认需求。审查结合当前源码、既有截图和本轮 API 36 独立模拟器实看。运行的是 `.local/ui-refinement/fixture-final-x86_64-profile.apk` 现有合成数据 Profile 产物，本轮未重新编译，不声称为重新构建的 HEAD。成绩、课程、考试和实践均为合成数据，不能用样例统计值判断真实业务计算是否正确。

## 覆盖与边界

本轮打开并采集截图、语义树：成绩、自定义绩点、加权成绩（另看深色）、考试列表、课表、课程列表、课程详情、搜索初始状态、实践项目列表与详情、工作时段列表与编辑对话框、时间滚轮、登录弹层与键盘状态、诊断空态、关于、服务条款、未登录付款码预览、任务编辑。

自定义课程代码映射仅审阅源码，因入口受登录状态约束，未进行真实登录。诊断有日志的复杂报告、真实付款、校园认证、物理设备、高字号和窄窗口不在此次运行验收范围。本轮没有执行付款、登录、清空日志、删除任务或保存课程权重。结束时恢复亮色模式、普通 Profile APK 并确认冷启动成功；未卸载或清除应用数据。

截图及语义树位于项目本地 `.local/secondary-review/`，不提交 APK 或截图到 Git。主要拼图：`grade-contact.png`、`academic-contact.png`、`forms-contact.png`、`practice-contact.png`、`settings-contact.png`。目录内少量中间快照名称为预期目标，实际仍停在入口，不能单凭文件名视为已进入对应页面；本报告列出的最终拼图已实际查看。

## 逐页发现与建议

| 页面 | 证据与问题 | 建议与实施边界 |

| 成绩 | 实看正常与自定义模式。大面积六指标容器、固定 81 高的学期选择容器、课程卡阴影叠加；只有一个学期时留白显著。`95 / 4.8`、`4.80/0.0` 等缺少数值语义。顶部两个图标虽有读屏标签，视觉含义仍不直观。 | 紧凑显示统计与学期摘要，为成绩/绩点/学分补清楚标签；保留全部指标、学年与学期统计范围，不能直接用只含名称的 Chips 丢掉现有摘要。 |
| 自定义绩点 | 未选课程整体降至 0.5 透明度，外观类似禁用；“长按清空”与其他操作样式不同。 | 维持文字可读，以复选框、边框或轻底色区分选择。提供明确模式与清空范围说明。源码中卡片 `onTapDown` 即改选择，取消手势未恢复，存在滚动误选风险；本轮未做手势复现，须作为独立交互缺陷验证，不能称为已复现。 |
| 加权成绩 | 学期选择与成绩页同样占空间；滑块容器明确限制为 8 dp，语义树轨道区域仅 21 像素高，值显示为“50%”；实际权重为 1.0。深色课程行背景与页面几乎相同，辅助文字弱。 | 扩大滑块实际布局/触控高度，轨道仍可细；为语义值提供课程名及 0.8/1.0/1.2 倍。补离散刻度说明，保留原范围、默认值、计算和写入回调。重置需明确作用范围；交互调整单独提交。深色用分组实体表面恢复分隔。 |

| 课表 | 筛选区占较多垂直空间；周网格高度固定 560，课程字号 10、地点 9，阅读小字困难；网格线没有可见呈现。 | 紧凑筛选同时保留秋冬/春夏课时信息和切换；采用轻量行列对齐线与适合窗口的单元格尺寸。保留现有七天结构、节次、冲突课程展示、点击详情、隐藏信息行为，不重写排课计算。 |
| 课程列表与详情 | 最新样式比成绩页更轻。列表长课程名在两行末尾出现单字换行，教师、成绩共行时较密；详情主体清楚，数据少时存在自然留白。 | 窄屏时让学分或辅助信息合理换行，保持完整课程名可达。课程详情保持基本信息、课时、考试的原顺序。只做间距、对齐、信息行复用，不为填满屏幕重排模块。 |

## 上游同步与优先级

付款码、工作时段、课程映射、诊断、成绩卡以及课表课程卡等文件相对本地上游基线无改动，说明部分问题来自原版。保持同步能力不等于保留已确认缺陷；通用修复应与 Edition 外观分开，便于贡献上游、未来删除重复补丁。

建议先处理付款码状态真实性（独立缺陷），再处理加权控件触控/语义、搜索范围文案和登录防重复提交。随后统一成绩/加权/课表的筛选外观与实体卡片。最后细化表单、实践说明、关于和条款排版。

优先使用现有共用设计组件；学期选择应支持可选摘要，不能为了复用丢掉成绩页原本显示的数据。主题与材质集中在设计层，原页面继续持有状态、控制器、路由与业务回调。每个修复小提交，视觉改动附对应状态截图，交互修复附针对性复现/回归；上游合并时逐项核对官方新增数据和功能，避免整文件覆盖。

本轮没有修改应用实现或已确认设计，没有执行新的全量测试。报告与 STATUS 文档执行 diff 格式检查。
