# Celechron Liquid Glass Edition · 最终 UI 盘查

盘查以 2026 年 11 月 19 日工作树为准（提交 `8fa1cf1` 加本地改动），对照本地官方上游 `724e54a`。本轮交付验收报告和改动建议。Android 运行证据来自使用当前源码构建的 API 36 x86_64 Profile 合成数据包。考试周、学分、余额及认证状态均按演示环境解读。

本轮的证据分三类。**运行**指本轮模拟器中打开并查看截图或语义树，**测试**指本轮 Flutter 回归或单独复现，**源码**指追到实际控件、颜色、手势和路由。另有少量历史证据单独注明。[本地源码索引](../.local/final-ui-audit/source-index.csv) 按路由、控制与手势、文字颜色、动效定位到文件和行号，共 62 个文件有命中，供后续逐项修复和复核。

## 跨页对齐的验收标准

- **材质**：导航、搜索和少量主操作做玻璃；正文、课表、成绩、二维码用可读的实体层。内容确实能从浮层周边看到，但控件文字对比足够。暗色与高对比分开查；关闭玻璃后保持同等可用。[Apple Materials](https://developer.apple.com/design/human-interface-guidelines/materials)
- **颜色和文字**：保持浅色求是蓝与既有暗色亮蓝，只作为用户已确认的强调；常规标题和正文用系统主文字，次信息用语义辅助色，删除/警示仍红。数值可用等宽数字。逐页检查 text scaling、截断、浅灰、多色块及长中文，避免靠颜色表达唯一状态。[Apple Color](https://developer.apple.com/design/human-interface-guidelines/color) · [Apple Accessibility](https://developer.apple.com/design/human-interface-guidelines/accessibility)
- **操作**：主动作一屏只突出一次；同组工具、退出和保存位置稳定。目标至少 44×44 逻辑点作为本项目检查线，图标要有可理解的标签。滑动、长按、拖动均提供等价按钮或无障碍操作，取消不提交。[Apple Toolbars](https://developer.apple.com/design/human-interface-guidelines/toolbars)
- **动效**：详情右滑入、短时选择用弹层、搜索从同一物件连续变化，按角色保持一致。没有动画也要能完成任务。测试低端机热机、60/120 Hz、滚动同时转场、快速返回和开关减少动态效果。历史模拟器帧时间不作为这轮实测流畅度。[Apple Motion](https://developer.apple.com/design/human-interface-guidelines/motion) · [Adopting Liquid Glass](https://developer.apple.com/documentation/technologyoverviews/adopting-liquid-glass)
