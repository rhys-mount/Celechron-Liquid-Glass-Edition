## 用户反馈后的复验

API 36 模拟器的设置页可在底栏下绘制内容，滚动末尾的「前往项目网站」整行停在底栏上方。带数据的组件回归覆盖任务列表末项可点、日程事项可滚且月历不移动。API 36 上也看到了「接下来」、日程和学业有数据时在底栏下绘制。新版课程列表在滚动后显示紧凑标题，学期选择器仍位于标题下方。课程详情展开了课程、课时和考试信息，实际打开成绩与加权成绩并切换了统计范围。覆盖考试学期切换、课表、搜索、实践详情及深色加权操作的 7 项组件回归均通过。

旧版 APK 在独立 API 36 模拟器上开启玻璃框架后采集了五个主页面，作为布局和交互对照。当前截图及日志位于 `.local/ui-review/`。

重新分组顶栏操作时，普通 APK 在玻璃开启状态下曾出现任务标签无响应，关闭玻璃的同包检查可进入任务页。将 Android 工具栏改为固定尺寸的轻量玻璃后，API 37.1 普通安装包连续切页 10 次并回到任务页，新增页和更多操作菜单可用。同一包还打开了设置里的可用工作时段、登录表单和关于页。全量 133 项测试通过，分析保留原有 21 条提示。ARM64 和 x86_64 已生成普通调试 APK。

API 36 模拟器在 Debug 模式载入 20 条任务和 18 条日程后，进入任务页可复现 Android 输入超时，关闭玻璃后也出现。使用同一代码与同一批数据构建 Profile 后，关闭和开启玻璃均可进入任务页。开启玻璃后，两张可见任务卡片绘制到底栏下，连续切页 10 次仍能回到任务页。滚到末尾时，最后一张可点卡片的底边在 y=2012，导航从 y=2116 开始。日历的 11 月 17 日日期格在事项滚动前后坐标一致。该轮试用使用普通 Profile APK，Debug 超时原因和物理设备的帧时间仍待核实。

普通 x86_64 Profile APK 已在 API 36 模拟器安装、冷启动并进入任务页。ARM64 Profile APK 已核验 ABI 和开发签名，待在手机上安装。两份试用包位于 `.local/ui-review/`，文件名分别为 `Celechron-UI-review-arm64-profile.apk` 和 `Celechron-UI-review-x86_64-profile.apk`。
